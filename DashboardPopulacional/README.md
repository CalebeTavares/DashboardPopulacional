# Dashboard Populacional

Projeto acadêmico em Java 21 para leitura, validação e organização de dados populacionais. A construção será feita por etapas:

1. Modelagem, estruturas de dados e orientação a objetos.
2. Interface gráfica com JavaFX.
3. Persistência com JDBC/SQLite.
4. Processamento em múltiplas threads.

## Requisitos

- JDK 21
- Maven 3.9 ou superior

## Executar a Parte 1

```bash
mvn clean compile exec:java
```

A primeira etapa executa uma demonstração no terminal com leitura do arquivo, validação, coleções, agregação e polimorfismo.
